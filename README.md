# MatchMind

An AI broadcast booth for football: a team of specialized agents turns a live stream of
synthetic match events into stats, "why it matters" insights, commentary and recaps, and
personalizes them for each viewer.

Built for the Microsoft "Inside the Game" Developer Hackathon. All clubs, players and
matches are fictional and generated by this project.

> Work in progress. See [docs/PLAN.md](docs/PLAN.md).

## Microsoft technology

- **Microsoft Agent Framework** (Python): agents and multi-agent orchestration
- **Microsoft Foundry Local**: on-device LLM inference, no cloud account needed
- **GitHub Actions**: CI
- **GitHub Copilot**: development assistance

Agents can also use Google Gemini's free API (`LLM_PROVIDER=gemini`) for higher-quality output.

## Quick start (backend)

Requires [uv](https://docs.astral.sh/uv/) and [Foundry Local](https://learn.microsoft.com/azure/foundry-local/)
(`winget install Microsoft.FoundryLocal`).

```bash
cp .env.example .env          # defaults to Foundry Local; no key needed
cd backend
uv sync
uv run python scripts/hello_models.py
```

The first run downloads the model (about 1.5 GB) and loads it, which can take a few minutes on CPU.
